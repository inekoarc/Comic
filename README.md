# 漫画管理器

一个本地漫画库管理和阅读工具。服务端扫描本机漫画文件夹，前端提供首页、漫画库、排行榜、分类、详情页、合集页和阅读器。评分、标签、观看次数、简介、分类封面等用户数据会保存到项目内的 `data/metadata.json` 和 `data/config.json`。

## 启动

```bash
npm start
```

然后打开：

```text
http://127.0.0.1:9000
```

Windows 下也可以双击 `ComicLauncher.exe` 启动，详见 [LAUNCHER.md](LAUNCHER.md)。

如果提示 `EADDRINUSE: address already in use 127.0.0.1:9000`，说明 9000 端口已经有一个漫画管理器或其他程序在运行。关闭旧进程后重新启动即可。

如果部署到服务器并希望从局域网/公网访问，可设置监听地址：

```powershell
$env:HOST="0.0.0.0"
npm start
```

## 漫画目录结构

推荐按一级分类、二级漫画文件夹组织：

```text
漫画根目录/
  分类A/
    漫画1/
      001.jpg
      002.jpg
    漫画2/
      001.png
      002.png
  分类B/
    漫画3/
      001.webp
```

系统会把一级目录识别为分类，把包含图片的文件夹识别为漫画。若漫画目录中存在 `元数据.json`，会尝试从 `tags` 初始化标签，并从 `intro` 初始化简介。标题形如 `[作者名(作者小名)] 作品名` 时，也会把作者名和作者小名补充为标签。

## 主要功能

- 漫画库支持搜索、分类筛选、标签筛选、页数区间筛选和分页跳转。
- 设置按钮会以浮层形式管理漫画根目录，支持添加目录、同步刷新和移除目录。
- 漫画库按分类展示；分类页每页展示 15 部，三行五列布局。
- 自动识别同一作品或同一文件夹下的合集，合集详情页支持按名称或更新时间排序，并可切换正序/倒序。
- 漫画详情页展示两行、每行 6 张预览图；点击预览图会以单页模式打开对应图片。
- 阅读器支持下拉和单页模式、继续阅读位置记录、自动滚动、方向键滚动速度、自适应宽度、亮度切换、上一部/下一部和阅读进度提示。
- 阅读器下拉模式默认只加载一组图片，读完后可继续加载下一组，减少一次性渲染带来的卡顿。
- 支持删除整部漫画、删除当前图片页、移动漫画到其他分类，并同步移动本地文件夹。
- 支持待看、收藏、快速标签、评分和简介编辑。
- 同步扫描时显示进度条，并会尽量复用本地索引，减少刷新等待。
- 排行榜支持按评分和观看次数排序，每页渲染 50 条。
- 支持自定义分类封面和随机漫画入口。

## 本地数据

- `data/config.json`：漫画根目录和分类封面配置。
- `data/metadata.json`：评分、标签、观看次数、简介等用户数据。
- `data/library-index.json`：扫描生成的漫画索引。
- `data/thumbs/`：缩略图缓存。
- 阅读位置等前端偏好会保存在浏览器本地存储中，不会写入项目数据文件。

以上文件会按本机环境生成，默认不会提交到 Git 仓库。

## 项目文件

- `index.html`：页面结构。
- `styles.css`：界面样式和响应式布局。
- `app.js`：前端状态、交互和渲染逻辑。
- `server.js`：本地 API、静态服务、目录扫描和文件操作。
- `tools/ComicLauncher.cs`：Windows 启动器源码。
- `build-launcher.ps1`：重新构建启动器的脚本。
